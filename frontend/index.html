        MA7 / MA25 / MA60 双周期顺势量化策略 实盘 · 模拟 · 回测 三端逻辑对齐

        核心思路：「双周期均线共振 + 多重过滤防追高 + 以损定仓 + 三阶梯保本移动止盈」。 只在顺大势且均线刚起势时进场，过滤震荡与脉冲末端追单，单笔亏损严格受账户风险比例控制，盈利后自动分阶段抬高止损并开启 MA7 移动追踪让利润奔跑。

        大周期趋势过滤
        HTF 同向排列
        默认 15m，不逆大势开单
        乖离率防追单
        ≤ 0.35% / 0.60%
        ATR(14) 自适应：偏离 MA25 ≤ 2.5×ATR
        假突破过滤
        反向影线 ≤ 1.5× 实体
        仅开仓当根校验，不清零确认计数
        移动止盈
        1.2R 保本 · MA25 追踪
        浮盈达 1.2R 移保本+0.1% 并沿 MA25 追踪
        一、开仓条件（全部满足）
        1大周期定方向（HTF）
        以高级框架均线排列（MA7 > MA25 > MA60 为多头，MA7 < MA25 < MA60 为空头）定大势，大趋势回踩期间不会放行逆势单。
        2小周期排列 + 斜率共振
        基础周期（如 15m / 1h）满足三线多头/空头排列，且最近 3 根 K 线 的 MA7 与 MA25 斜率持续同向发散。
        3ATR 自适应乖离 & 反向影线过滤
        • 乖离率防追高：收盘价偏离 MA25 不超过 2.5 × ATR(14)，全周期自适应波动率；
        • 假突破过滤：仅拦截反向长影线（做多拦长上影、做空拦长下影 > 实体 1.5 倍），且只在开仓当根检查，不中途清零确认计数。
        4收盘价连续确认（Bar Close）
        仅在 K 线正式收盘时刻计数，必须连续 N 根（如 2 或 3 根）完整收盘 K 线全部满足条件才开单；同币种同时只持 1 单。
        二、仓位与风控管理
        1初始止损定锚（1R）
        以信号 K 线的 MA60（或信号 K 线高低点）作为结构止损位，同时强制保留至少 0.3% 的最小保护距离，防止止损过窄被正常波动扫出。
        2以损定仓公式
        开仓数量 = (账户资金 × 风险比例) ÷ (止损距离 + 预估双边手续费与滑点)
        将双边手续费与滑点计入单位风险，哪怕止损较窄，触发初始止损时的真实净亏损也严格控制在设定比例（如 1.2%）以内，且总名义价值不超过 可用保证金 × 杠杆 × 95%。
        3每日最大亏损熔断
        按 UTC 自然日实时统计当日已平仓累计盈亏，一旦亏损达到全局设置的「每日最大亏损 %」（默认 5%），当天自动熔断暂停开新单。
        4实盘精度与安全保护
        实盘下单前自动按币安合约步长格式化数量与止损价，平仓市价单强制携带 reduceOnly，避免意外反手开仓。
        三、出场与三阶梯锁盈
        阶段 / 触发条件 止损与平仓动作
        初始阶段
        浮盈 < 1.2R        		 仅保留初始结构止损（触及记为 初始止损）；取消 0.7R 过早保本与 MA60 穿线提前洗盘离场。
        趋势追踪
        浮盈 ≥ 1.2R        		 止损自动移至 入场价 ± 0.1%（覆盖手续费）并开启 MA25 移动止盈：止损沿 MA25 × 0.9995 / 1.0005 单向推进，触及移动止损或收线破 MA25 才平仓。

        关闭后在模拟与实盘中均不参与监控和开单
